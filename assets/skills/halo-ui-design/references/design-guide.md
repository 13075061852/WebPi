## 视觉令牌

没有品牌要求时可用下列起点；已有主题时映射为项目的语义变量，不逐元素硬编码，也不为局部修复覆盖全局主题。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 底层、侧栏 | `#f5f5f3` | `#0b0b0a` |
| 主画布 | `#fcfcfb` | `#151515` |
| 独立面板 | `#ffffff` | `#1a1a19` |
| 输入框、浮层 | `#ffffff` | `#20201e` |
| 可选强调色 | `#d97757` | `#d97757` |
| 强调色悬停 | `#cc5a36` | `#cc5a36` |
| 轻分隔 | 黑色 8% | 白色 8% |
| 强分隔 | 黑色 16% | 白色 16% |

强调色用于少量重点，不强制替换用户品牌，也不默认将陶土色按钮配白字；实际检查文字与背景对比度。浅色背景差别很小时配合留白或分隔表达边界。

| 控件角色 | 圆角起点 |
| --- | --- |
| 快捷键、微标签 | 4px |
| 紧凑按钮 | 6px |
| 标准按钮、输入框 | 8px |
| 小面板、附件条目 | 10px |
| 代码块、预览面板 | 12px |
| 对话框 | 16px |
| 用户消息 | 18px |
| 聊天输入容器 | 20px |

标准桌面控件可从 32px 高起步，紧凑操作 24–28px，主操作 40px；触屏增大可点击区域。嵌套圆角随内边距递减，不机械套同一个半径。聊天正文宽度可从 672–768px 起步，数据表、编辑器和展示型网站按内容安排。

正文采用系统字体栈，Windows 中文可使用 Segoe UI、Microsoft YaHei、sans-serif；代码使用 Consolas 等系统等宽字体。只在适合的展示标题使用系统衬线字体。不要下载专有字体来追求一致。细边框默认 1px；高 DPI 的 0.5px 仅用于装饰分隔，需观察是否清晰。键盘焦点保持明显，不因去除装饰描边而删除焦点反馈。

## 组件与状态

- 一组主操作只有一个显著主按钮，其余操作用低强调按钮；容器已有边界时，内部工具按钮优先背景反馈，避免重复闭合边框。禁用、悬停、按下、选中与键盘焦点可区分。
- 助手正文适合透明背景和自然段排版；用户输入可用轻底色气泡。长链接与代码分别处理换行、横向滚动；列表标记留在消息内边距中。
- 错误用紧凑摘要与可展开详情，不能只靠红色表达状态。是否合并、重试或保留历史由业务需求决定，视觉规范不改变执行语义。
- 滚动区域给滚动条留出空间，可用 `scrollbar-gutter: stable` 配合内边距；渐隐遮罩仅在确有溢出时使用，不能遮住末行文字或操作。

## 动效

上游第一篇的时序起点：微反馈 60ms、切换 120ms、一般过渡 200ms、抽屉 300ms、环境转场 450ms。普通入场可用 `cubic-bezier(.165,.84,.44,1)`，吸附切换可用 `cubic-bezier(.32,.72,0,1)`。不要求所有动画使用弹簧库；避免持续呼吸、模糊或逐字动效干扰阅读。

高度未知的展开区可采用 Grid `0fr → 1fr`，内层设置 `min-height: 0; overflow: hidden`；切换 `aria-expanded`，收起后让隐藏内容无法获得键盘焦点。退出完成后再隐藏或卸载，否则看不到收起动画。减少动态效果时取消位移、缩放及循环效果，保留状态变化。

## 自适应与输入

面板优先使用容器查询；上游 576 / 480 / 384 / 320px 可作为检查点而非强制断点。Flex/Grid 子项设置适当的 `min-width: 0`；必要时使用 `minmax(0, 1fr)`。网址、端口和长文件名不能挤掉主操作。折叠文字后保留可访问名称；表格宽度不足时局部横向滚动。

中文输入用 compositionstart / compositionend 维护合成状态，并结合键盘事件的 `isComposing`；合成确认不能触发表单发送。拖动分隔条可用约 4px 移动门限区分点击与拖拽，使用指针捕获并在结束时恢复 iframe 输入。不要为拖拽禁用整个页面交互。

实际验证内容：窄屏有无横向溢出、长文本与错误是否挡住操作、展开收起是否连续、Tab 焦点顺序和 Escape 关闭是否正常；聊天类页面额外验证中文输入与用户上滚时的行为。
