---
name: halo-imagegen
description: 使用已登录的 OpenAI Codex 订阅生成图片、插画、海报、背景或按参考图修改图片。
---

使用内置 image_generate 工具，复用 Pi 的 OpenAI Codex 订阅账户。无需启动 Codex 或配置 API Key；生成会消耗订阅额度，是否可用取决于账户权限。

- prompt 保留用户意图，简要包含用途、主体、风格、构图和必要限制。图片内文字用引号标明。
- 编辑时通过 references 传入用户指定的本地图片路径，并明确只改什么、保留什么。先用 read 查看参考图；最多3张，每张8 MB以内。
- 每次生成一张。未被要求时不要额外生成多个候选；失败不原样自动重试，不切换收费 API。
- 工具只返回最终文件路径和大小。用 read 检查图片后再交付链接；未看过就不能声称视觉验证通过。
- 默认输出在当前项目 output 中，使用唯一文件名避免覆盖。用户指定其他目的地时再移动最终文件。不要把 base64、脚本、调试日志写入项目。
- 简单确定性的图表和已有 SVG 修改继续使用对应代码工具。
