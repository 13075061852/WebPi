# Theme image collection

30 independent wallpapers generated with the built-in ImageGen tool, September 12, 2026. Five categories with six images each. No procedural illustration placeholders.

Runtime files: `scene-<id>.webp` (1672 × 941, WebP quality 90) and `scene-<id>-thumb.webp` (480 × 270, quality 82). Only file encoding and thumbnail scaling were performed after generation; original compositions are unchanged. Combined assets: 11,629,988 bytes. Originals remain in Codex generated_images.

`scripts/build-theme-collection.mjs` rebuilds metadata, palettes and markup from the existing raster assets; it does not generate artwork. Missing assets cause it to fail.
