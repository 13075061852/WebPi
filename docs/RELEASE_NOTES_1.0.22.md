## Pi Halo 1.0.22

- 消息队列改为直接显示操作按钮，移除展开和“等待执行”文字；支持单击介入、撤回及重新编辑，重新编辑时恢复正文和图片并保留已有草稿。
- 压缩上下文时增加旋转等待动画，支持压缩期间发送消息排队，并在压缩结束后继续执行；恢复会话时同步待处理消息。
- 增加 AI 回复完成或异常结束的桌面通知，点击通知可返回应用。
- 修复 Windows 开发版与安装版的任务栏应用标识及图标分组。
- 补齐队列、上下文压缩、通知及应用标识的离线回归验证，更新内置版本历史。

Windows x64：下载 Pi-Halo-Setup-1.0.22.exe 安装，或在软件内检查更新。
