# 软件更新说明

[返回项目首页](../README.md) · [全部文档](README.md)

## 自动检测与下载

安装版启动后立即检查更新，此后每分钟检查一次。左下角「检查更新」也可以手动触发检查。

发现新版本后自动后台下载，按钮显示下载百分比；下载完成后提示新版本可用，按钮变为「重启更新」。下载不会自动重启应用，也不会在退出时自动安装。

开发模式和显式离线模式不执行定时检查。自动检查遇到错误时保留原状态；手动检查失败会显示错误并允许重试。

## 安装与正在运行的任务

点击「重启更新」后会先检查正在运行的任务：

- 没有运行任务时，开始退出并打开安装向导。
- 有运行任务时，提供立即安装、等待任务结束或取消的选择。
- 选择等待后，按钮显示「取消等待」，可撤销此次等待；撤销后安装包仍保留。

安装使用可见的安装向导，完成后重新启动应用。

## 按钮状态

| 显示 | 含义 |
| --- | --- |
| 检查更新 / 已是最新 | 可以手动重新检查 |
| 检查中… | 正在查询更新源 |
| 后台下载 / 下载 N% | 发现新版本，正在下载 |
| 重启更新 | 安装包已下载，点击开始安装流程 |
| 检查任务… | 正在确认运行任务 |
| 取消等待 | 等待任务结束后安装，点击可取消等待 |
| 正在更新… | 安装已开始 |
| 重试更新 | 上次更新失败，可查看按钮提示并重试 |

## 更新源与维护

更新源由 `package.json` 的 `build.publish` 指定，当前为 [13075061852/WebPi](https://github.com/13075061852/WebPi/releases)。客户端必须能匿名访问公开 Release 与更新资产，不应包含 GitHub 私人令牌。

只有正式公开、版本高于当前安装版的发布才会成为更新候选。维护时需配套保留安装 EXE、对应 blockmap 和 `latest.yml`，文件名称及摘要须与更新元数据一致。

正式发布与失败重试统一按 [Windows 发布流程](RELEASING.md) 执行。标签推送不会自动触发云端构建；默认使用本地 Windows 构建并上传，云端仅作明确请求后的手动后备。
