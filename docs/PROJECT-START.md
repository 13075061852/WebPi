# 本地项目启动与预览

启动方式会在前端页面验证成功后按项目记忆，包括托管服务命令、相对工作目录和预览地址。命令经系统加密后保存。后续先复用成功方案并等待页面就绪，不调用 AI；命令退出、页面未就绪或原端口已有服务时，清理本次托管进程，再交给 AI 分析，成功后更新方案。仅复用外部服务而没有托管命令时，不记录可重放方案。取消启动不会触发 AI 回退。

项目标题旁的“▷ 启动”会使用当前选定模型创建独立的内存 AI 会话。助手读取项目说明和配置，使用托管工具启动前端及所需服务，确认本机前端 URL 后自动打开中间预览。启动消息不写入前台聊天记录。

项目下方显示启动状态、端口、日志和停止按钮。点击端口可重新打开预览。切换对话或项目不停止服务；删除所属对话、移除所属项目、手动停止或退出应用会清理应用启动的进程。复用已有服务时不接管或关闭外部进程。

常驻服务通过 `project_service_start` 托管。Windows 使用 ConPTY 保留启动器及其子进程，停止时清理进程树；应用退出会等待清理完成。分析最长十分钟，启动后定期检查页面是否仍可访问。AI 遇到缺失凭据或依赖错误会在状态和日志中报告，不把纯文字声明视为启动成功。

验证：

- `node test/verify-project-runs.mjs`：重复启动、地址校验、所属会话隔离、取消、项目清理和错误状态。
- `node test/e2e/e2e-project-runs.mjs`：隔离配置、真实 Electron 和 Pi SDK、本地模拟模型驱动托管工具；验证实际网页、自动预览、端口入口、前台历史不变、后台常驻、删除会话、移除项目及应用退出清理。不使用个人模型账户或真实项目服务。

当前面向本地项目。远程服务器仍使用现有 SSH 端口预览入口。
