## Pi Halo 1.0.21

- 优化模型用量统计缓存，减少重复读取会话记录；合并对话过程中的重复写盘，保留完成任务和退出时的保存检查。
- 终端组件改为首次使用时加载，减少启动加载内容；修复空项目切换时重复创建新会话的问题。
- 收紧会话文件访问范围，完善链接别名、任务进行中保护和删除前的文件检查，兼容已有项目与服务器历史。
- 修复 Windows 文件监听对隐藏目录、依赖目录的过滤；文件树选择不再重建整个列表，增加键盘导航。
- 插件更新检查增加超时和并发限制，网络异常时保留已安装插件信息；完善弹窗焦点及键盘操作。
- 平板预览边框由 16px 收细到 8px，同步调整圆角和摄像头装饰。
- Electron 更新至 44.9.3，补齐运行依赖声明，清理已停用代码与冗余构建配置。
- 扩充隔离的离线回归检查，补齐已发布版本的内置更新历史。

Windows x64：下载 Pi-Halo-Setup-1.0.21.exe 安装，或在软件内检查更新。
