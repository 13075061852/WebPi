## Pi Halo 1.0.18

- 优化对话切换与新建响应，增加等待和过渡动画，修复新建页面反复跳转与旧内容闪回。
- 强化当前对话高亮，移除项目文件夹的选中底色；空白新对话在发送消息后进入列表。
- 按对话记住预览区开关及已打开文件或网页，修复切回后内容丢失、终端链接预览无法退出的问题。
- 修复文件引用补全拦截回车发送；文件树支持一键添加到当前对话，可复制的文件卡片提供复制入口。
- 修复终端关闭后编号持续累加，统一文件树操作图标和插件卡片布局，调整开关、安装按钮的垂直居中。
- 修复液态玻璃主题下补全菜单与聊天内容透叠。
- 安装版启动后立即检查更新，此后每分钟检查一次；发现更新后台下载，安装仍由用户确认。
- 新增内置视频中文字幕技能，完善硬字幕 MP4 与 SRT 的生成流程。
- 重整项目首页、使用指南、开发指南及文档导航，修正过时说明。

Windows x64：下载 `Pi-Halo-Setup-1.0.18.exe`，或通过软件左下角更新入口升级。
