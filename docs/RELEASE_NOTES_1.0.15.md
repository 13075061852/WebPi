## Pi Halo 1.0.15

- 记住窗口关闭前的大小和位置，优化窄屏下侧栏、预览区的折叠与自动展开。
- 预览区支持输入网址；聊天中打开网站、点击终端链接默认使用内置预览，可继续观察和操作页面。
- 修复终端缩放后的空白、重复输出和错位；选中文字时 Ctrl+C 复制，未选中时保留中断命令。
- 任务运行期间发送的消息默认排队、依次执行；在队列中二次确认后才介入当前任务，保留消息附件。
- 精简请求失败提示，合并同轮重复错误并显示次数，保留历史错误；移除重试按钮，补全工具详情展开收起动画。
- 修复 Word 文档预览分页，优化代理配置窄屏布局、内滚动及滚动条对齐。
- 修复 OpenAI 订阅登录缺失设备标识，以及插件安装时额外弹出 CMD 窗口的问题。
- 更新视频、海报、网站和游戏入口提示词，附可核查来源；优化启动界面和预览控件。
- 补齐历史版本备用数据，改进本地发布候选包复用和验证。

Windows x64：下载 `Pi-Halo-Setup-1.0.15.exe`，或通过软件内“检查更新”升级。
