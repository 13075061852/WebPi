# 预览与弹窗动画验证

2026-09-16，Windows / Electron 44 / Chromium 152。此前直接取消宽度动画的实现已替换为完整过渡动画。

## 交互与实现

- 侧边栏展开/收起、预览展开/收起、专注模式和电脑/平板/手机切换保留约 280 毫秒的位移、尺寸过渡。
- 侧边栏等工作区变化使用浏览器快照，由固定尺寸画面的 transform 驱动。嵌入页面在移动期间保持原视口，滑动结束后只接收最终尺寸；不刷新页面、不改变原文件。
- 三种设备之间切换时，先用不透明遮罩覆盖屏幕内容，只让设备框保持尺寸动画。最终视口绘制完成后，用 120 毫秒淡出遮罩；连续切换会保持遮盖，若揭开途中再次选择设备，会立即恢复遮罩，避免露出拉伸或挤压的中间画面。HTML、图片、视频和服务器预览使用相同的屏幕覆盖位置。
- 设备外壳改用独立的轻量装饰层，同时过渡宽高、位置、内边距和圆角；边框厚度保持不变，摄像头、手机状态栏和电脑底座同步淡入淡出。外壳不再缩放旧设备截图，避免先压扁旧外壳、结束后再跳到新外壳。装饰层只复制外壳和状态栏，绝不复制 iframe/webview。
- 设备外壳和工作区使用同一条先加速、后减速的 280 毫秒曲线。调整主窗口尺寸会取消旧过渡并清理装饰层；窗口隐藏也会结束过渡和遮罩淡出，恢复时保留原页面。动画的完成 Promise 在可能取消之前保存，避免等待一个取消后新建的未完成 Promise。
- 先让快照完成绘制，再启动动画时钟，避免首次纹理绘制打断滑动。动画准备有实际开销，本机凤凰页面采样约几十至一百多毫秒；这部分没有算入动画期间的帧间隔。
- 工作区使用元素范围的 View Transition，弹窗可在滑动过程中正常显示在上方。
- 设置、模型、思考级别等弹窗使用 200 毫秒打开、160 毫秒关闭动画。关闭中途重开，从当前透明度和位置继续，避免闪跳或被旧回调误隐藏。图片放大弹窗同样有开关动画，Escape 会先完成关闭动画再移除窗口。
- 预览动画在弹窗或工作区过渡期间暂停，随后按界面状态恢复；保留页面实例与滚动位置。系统启用“减少动态效果”时尊重该设置。

## 真实页面采样

使用用户凤凰 Canvas 页面的副本，放在独立工作区和应用配置中测试。原页面未修改。测试同时检查实际过渡时长、中间 transform / opacity 和预览页面 ID；不能用直接切到最终状态通过测试。

下表测量的是**动画时钟实际运行期间**主界面 requestAnimationFrame 回调的最大间隔，不等同于独立测量显卡呈现 FPS。采样时未并行运行其他测试；复杂预览页面在动画结束后仍有自身的绘制开销。

| 操作 | 动画期间最大回调间隔 |
| --- | ---: |
| 侧边栏收起 / 展开 | 10 / 10 毫秒 |
| 平板 / 手机 / 电脑切换 | 20 / 20 / 10 毫秒 |
| 预览收起 / 展开 | 10 / 30 毫秒 |
| 设置打开 / 关闭 | 20 / 10 毫秒 |
| 模型打开 / 关闭 | 10 / 10 毫秒 |
| 思考弹窗打开 / 关闭 | 10 / 10 毫秒 |

这次采样中，主要滑动动画有 25–28 次中间更新，弹窗有 16–20 次。上述数值只描述本机测试，不保证任意预览页或设备都达到同样帧率。

## 回归与复现

- 动画基础实现此前通过 37 项回归；本次外壳改动重新验证预览暂停/恢复、回调取消、尺寸绘制、竞态和完成后刷新隔离，231 个文件语法检查及 ESLint 通过。
- 真实 Electron 验证完整动画、中途反向、打开尚未准备好时关闭、快速设备切换、弹窗与工作区同时过渡、窗口尺寸变化、图片放大弹窗、深浅色和减少动态效果。
- 设备切换额外验证：快照移动前遮罩已完整覆盖、动画中间帧内容被遮住、揭开时被下一次切换打断、结束后遮罩移除、最终视口尺寸正确且页面 ID 不变。
- 外壳覆盖三种设备的全部六种切换方向：检查 0/140/280 毫秒的实际边框位置、尺寸与圆角，起点和交接终点与真实外壳误差小于 0.6 像素；中途边框厚度不变、没有 scale 或额外嵌入页面，结束和窗口调整后装饰层均清理。
- 分别在外壳变化和遮罩淡出时触发隐藏状态，检查清理完成和页面实例保持不变。媒体测试等待窗口实际显示、设备过渡完成后检查最终视口，替代固定等待 650 毫秒。
- 完整视频设置 E2E 通过，覆盖视频、图片、设备外框、HTML 视口及历史恢复。

视频设置 E2E 首轮曾在 Escape 关闭设置时超时，加入失败状态诊断后整轮通过，尚未复现原因；该失败发生在设备切换测试之前。诊断会记录可见弹窗、原生选择器和动画状态，便于再次出现时定位。

本次媒体回归还捕获了窗口隐藏时过渡未清理、后续视口未同步的问题；增加隐藏时的取消和清理后，完整回归通过。

运行 `npm run test:ui-motion` 可使用内置 Canvas 测试页。复测指定文件时运行：

```powershell
npm run test:ui-motion -- "--preview-file=C:\path\to\preview.html"
```

测试复制输入文件，不修改原文件或现有账户数据。结果和中间帧截图写入命令输出的 `tmp/startup-recovery/run-*` 目录；最终验证记录另存于本地 `test/results/ui-performance/`。这些生成文件不进入安装包。
