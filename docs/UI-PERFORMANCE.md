# 预览切换与弹窗性能验证

2026-09-16，Windows / Electron 44，使用用户提供的凤凰 Canvas 页面副本和独立应用配置测试。原页面文件未修改。

预览宽度原先同时动画化网格列宽、容器 padding、设备框尺寸和裁切圆角。现在折叠、展开和电脑/平板/手机切换直接应用最终尺寸，不再对嵌入页面逐帧改变视口；页面实例、滚动和运行状态保持。复杂页面仍需绘制一次新尺寸，这不是对任意页面渲染时间的保证。

弹窗保留 140–180 毫秒的淡入/位移动画，移除整窗背景模糊和面板缩放。弹窗显示或预览收起时，暂停预览页面的 requestAnimationFrame 与正在运行的 CSS 动画，恢复显示后继续运行。暂停期间若发生尺寸变化，允许一次绘制，避免 Canvas 清空后留下空白；取消回调、重复暂停、快速重开及页面自身原先暂停的动画均有检查。此机制不暂停应用任务或重新加载预览。

模型弹窗每次打开只请求一次模型列表；设置中的模型列表改为进入相应页面时加载。

## 相同页面、相同操作的采样

修改前基线为 `ac3bb19`。每项操作后采集一秒 `requestAnimationFrame` 回调及 Chromium Performance 的 LayoutCount；这些回调数是动画调度流畅度指标，并非显卡实际呈现帧的独立测量。最终采样没有同时运行回归测试。

| 操作 | 修改前布局次数 | 修改后布局次数 |
| --- | ---: | ---: |
| 收起侧栏 | 9 | 1 |
| 展开侧栏 | 10 | 1 |
| 平板 | 9 | 1 |
| 手机 | 8 | 1 |
| 电脑 | 10 | 1 |
| 收起预览 | 38 | 1 |
| 展开预览 | 10 | 1 |

| 弹窗打开后的一秒采样 | 修改前动画回调 | 修改后动画回调 |
| --- | ---: | ---: |
| 设置 | 31 | 93 |
| 模型 | 40 | 96 |
| 思考级别 | 41 | 95 |

凤凰页面持续播放时仍有较高的画布绘制开销，设备切换采样中仍可出现 80–130 毫秒的单帧间隔。因此这里采用快速尺寸切换，不承诺复杂预览页自身始终达到 60 FPS。

## 验证

- 37 项现有及新增回归通过，语法与 lint 检查通过。
- 真实 Electron 验证弹窗关闭后原页面动画继续、连续打开/关闭不会误隐藏、快速设备切换结果正确、页面 ID 不变、尺寸一致、浅色/深色和减少动态效果设置。
- 完整视频设置 E2E 通过，覆盖视频、图片、设备外框、HTML 视口及历史恢复。
- 动画调度单元验证包括重复暂停、恢复后的原回调 ID 取消、调整尺寸只绘制一次、同帧取消其他回调，以及保留页面自身的暂停状态。
