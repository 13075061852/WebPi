# 数字人视频方案

## 当前已实现

设置中增加“数字人”页面，分别配置人物照片和声音样本，点击“保存配置”后复用。

聊天输入框的“数字人视频”入口只填写本次视频的台词、场景、动作与表现，以及画幅和清晰度。上方显示已保存的照片与声音摘要，可跳回设置修改配置。

- 照片：支持批量导入并勾选最多 9 张参考照，逐张移除；JPG、PNG、WEBP，单张最大 20 MB；缩略图保留完整画面。边长 256–5760 像素，宽高比 0.4–2.5。
- 声音：支持本页麦克风录音（结束后保存为单声道 WAV）及上传 MP3、M4A、WAV，最大 20 MB，时长 10 秒至 5 分钟；可以试听、更换、移除。
- 配置：照片与声音选择独立保存，不改变生成草稿。
- 草稿：台词、场景、动作及生成选项在点击“保存草稿”后持久保存。重开应用可恢复；保存草稿不改变人物配置。
- 长台词：估算口播时长，提供约 15 秒一段的建议，保留原文和标点。估算不会代替后续实际配音时长。
- 当前生成按钮显示“生成视频 · 未接通”，保持禁用。所有导入和草稿操作在本机完成，尚未上传素材、克隆音色或调用收费服务。

## 声音样本怎么准备

1. 在安静房间点击“开始录音”，或使用手机录音机录制本人自然说话的声音。页面显示计时，可结束试听或取消；关闭设置即释放麦克风，未完成的录音不保存。
2. 建议录制 **30–60 秒**，用平时的语速和音量，避免背景音乐、其他人说话和长时间停顿。
3. 导出 MP3、M4A 或 WAV，在面板中点击“上传音频”，试听确认声音清楚。
4. 样本用于学习音色，不需要朗读最终视频的台词；每次视频要说的话填写在“台词”中。

格式、10 秒至 5 分钟和 20 MB 上限依据 [MiniMax 声音克隆上传要求](https://platform.minimax.cn/docs/api-reference/voice-cloning-uploadcloneaudio)。30–60 秒是本功能的录制建议。

录音区域直接显示约 50 秒的三段朗读示例，涵盖自然陈述、提问、数字和轻微情绪变化。用户也可以朗读其他自然文本，本地导入不要求提交逐字稿。

导入后通过实际音频解码检查时长，拒绝无法解码的文件、超长或过短录音、完全静音；音量较低、疑似破音和静音较多会提示重新检查。信号检查不能判断是否多人说话、是否存在背景音乐或是否属于某个人，因此仍需用户试听。界面明确区分“本地音频校验”与“克隆音色”。

## 本地素材与草稿

素材复制到应用数据目录的 `digital-human/assets/`，以随机 ID 命名；`digital-human/draft.json` 保存素材记录、独立的 `profile`（照片与声音选择）及 `draft`（台词、场景、动作、生成选项）。旧版混合保存的数据读取时自动迁移，下次保存时写入分离结构，保留原有素材和文字。选择文件使用系统文件对话框。

预览通过仅允许已登记素材 ID 的 `halo-preview://digital-human/<id>` 提供，不接受任意文件路径。支持音频范围请求；素材被外部删除后提示重新导入。“移除”仅删除应用导入的副本，保留用户原始文件。

## 后续收费接口接入方案

拟优先使用 MiniMax 的声音克隆、配音和 H3 视频能力，按以下步骤接入：

1. 用户选定声音样本后上传并创建音色。保存供应商、账户范围、音色 ID 与状态；再次使用同一音色时复用，避免重复克隆。
2. 使用克隆音色对用户原始台词生成配音，先提供试听。根据实际音频时长分段；不截断、不改写台词。
3. 用人物照片、各段配音和场景/动作描述提交视频任务。H3 支持参考图片、参考音频及文字提示；支持 768P/2K，单段 4–15 秒。参考音频必须为 WAV/MP3，单段 2–15 秒、最大 15 MB，总时长不超过 15 秒。[MiniMax H3 接口](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)
4. 长台词需要多段生成与后续拼接；当前界面仅提供分段建议，尚未实现配音、视频任务或拼接。
5. 生成完成后保存本地视频和远程地址，接入现有视频历史与播放入口；区分失效、删除和网络失败。
6. 克隆、配音和视频分别记录消耗，提交前展示本次费用估算。使用普通 API Key，账户能力和报价在正式接入时重新核对。

方案判断：H3 接收的是参考音频，不能仅据接口参数保证台词逐字准确、音色一致或口型同步。正式接入需先做真实成片验证；若达不到口播要求，再采用专用口型驱动方案，并单独处理场景和动作。当前不宣称已验证生成效果。

## 验证

- `node test/verify-digital-human.mjs`：导入校验、配置/草稿分离、旧数据迁移、原文件保留、素材范围读取、删除及目录约束。
- `node test/verify-voice-sample.mjs`：时长边界、音量/破音/静音检查和台词分段完整性。
- `node test/e2e/e2e-digital-human.mjs`：隔离账户的真实 Electron 测试，验证设置页配置照片/声音、生成页填写台词、配置跳转、录音解码与试听、错误录音拒绝、两类数据独立保存与恢复、原文件保留及底部按钮可见。外网请求为零。
